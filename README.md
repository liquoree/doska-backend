# doska-backend

Backend-часть приложения [doska](https://github.com/liquoree/doska) — простого сервиса для управления задачами и проектами, вдохновленного концепцией Kanban-досок.

Данный репозиторий содержит серверную часть проекта и отвечает за работу с данными приложения: пользователями, проектами, досками и задачами. Backend работает в связке с frontend-частью приложения и предоставляет API для взаимодействия с клиентом.

## Возможности

- Хранение данных пользователей
- Управление проектами и досками
- Хранение и обработка задач
- Связь пользователей с проектами и досками
- Хранение статусов задач
- Базовая система регистрации и авторизации

## Технологии

FastAPI, SQLModel, PostgreSQL

# doska-backend

Backend part of the [doska](https://github.com/liquoree/doska) application — a simple task management system inspired by the Kanban workflow concept.

This repository contains the server-side part of the project and is responsible for managing application data: users, projects, boards, and tasks. The backend works together with the frontend application and provides an API for client-side interaction.

## Features

- User data storage
- Project and board management
- Task storage and processing
- User-project-board relationships
- Task status management
- Basic registration and authentication system

## Technologies

FastAPI, SQLModel, PostgreSQL
